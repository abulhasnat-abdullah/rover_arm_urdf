# arm_sim (ROS 2)

This package contains the URDF, meshes, textures, and launch files for the arm_sim robot, ported to ROS 2.

## Structure
- `config/`: Configuration files
- `launch/`: ROS 2 launch files
- `meshes/`, `textures/`: 3D assets
- `urdf/`: URDF and related files

## Build
Use `colcon build` from the workspace root.
